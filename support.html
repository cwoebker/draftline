Support

Draftline is made by one person. Questions and bug reports are welcome and read.

Report a problem or ask a question

Open an issue on GitHub. Please include which device and version you are on and, for anything involving a file, what the commit on GitHub looked like versus what you expected.

Signing in

Draftline signs in with GitHub through the Draftline GitHub App, or with a fine-grained personal access token. A token needs Contents read and write on the repositories you want to edit; add Pull requests, Checks and Deployments read to see the pull request row. If the app shows fewer checks than GitHub does, the token is missing one of those.

Files over 1 MB

GitHub's API does not serve files larger than 1 MB to apps, so Draftline cannot open them and says so. Edit those on GitHub directly.

Removing your data

Sign out in Settings to remove your credential, and delete the app to remove the cache. Details are in the privacy policy.
